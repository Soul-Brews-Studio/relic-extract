$ relic-extract --help
relic-scan month files -> per-stream, deduped, chunked parts for embedding

Usage: relic-extract [OPTIONS] <COMMAND>

Commands:
  init     Write ~/.arra/relic.toml with the defaults (kept if it exists)
  config   The settings in effect: the file merged over the defaults
  run      Cut the months that changed (or --months) for every stream that is on (or --stream)
  status   Per stream: months, chunks, distinct texts, newest message
  tui      The analyse report in the terminal: overview, months, clean rules with samples, biggest, repeats, repos
  analyse  What a run would cut and what the clean step takes out, without writing anything
  help     Print this message or the help of the given subcommand(s)

Options:
      --config <CONFIG>  another config (default ~/.arra/relic.toml, or ARRA_CONFIG)
  -h, --help             Print help
  -V, --version          Print version
